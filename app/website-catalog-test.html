Produktliste auf einer Webseite einbauen

Kopiere den Code in einen HTML-Baustein deiner Webseite. Die Liste lädt beim Öffnen den aktuellen Stand aus SMA. Besucher können sie zusätzlich über „Aktualisieren“ neu laden.

Der Bereich ist 640 Pixel hoch und passt sich der verfügbaren Breite an. Längere Listen werden darin gescrollt. Unterstützt dein Webseitenprogramm keine eingebetteten Fenster, verwende den Shop-Button.

Zur Einbauhilfe für den Shop-Button

Die Liste zeigt öffentlich freigegebene Produkte. Warenkorb und Kaufabwicklung bleiben im SMA-Shop.
